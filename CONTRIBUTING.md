# Contributing

## Guidelines

- One resource per pull request.
- Resource must be actively maintained (updated within the last 12 months).
- Include a brief description (one sentence) explaining what makes the resource useful.
- Follow the existing format: `[Name](URL) - Description.`
- Place your resource in the correct category.
- Check for duplicates before submitting.

## Quality Bar

Resources should be:
- **Practical** — usable by someone building or operating agents today.
- **Substantive** — not just a landing page or marketing material.
- **Maintained** — actively developed or recently updated.

## Format

```markdown
- [Resource Name](https://url) - One-sentence description of why this is useful.
```
